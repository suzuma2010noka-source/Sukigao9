好き顔9選 v10
================

【遊び方】
index.html を開きます。メンバー一覧のCSVを読み込みますので、ローカルで開く場合はブラウザによって読み込みが制限されることがあります。GitHub Pagesに配置して使う方法がおすすめです。

【GitHub Pagesへの置き方】
このフォルダの中身（index.html、style.css、app.js、members.csv、imagesフォルダ）をGitHubリポジトリの公開フォルダにアップロードしてください。以後、メンバーの更新は members.csv、写真の更新は images 内だけ差し替えれば反映できます。サイト本体のHTML/CSS/JavaScriptは編集不要です。

【メンバー一覧の更新】
1. Excelで名簿を編集します。列名は name / group / category の3列にしてください。
2. Excelの「名前を付けて保存」でCSV UTF-8形式に保存し、ファイル名を members.csv にします。
3. GitHub上の members.csv を差し替えます。
4. name、group、category の列名を変更したり、列の順序やCSVの形式を変えたりしないでください。カンマを含む値はExcelからCSV UTF-8で保存すれば正しく扱われます。

【写真の追加】
1. images フォルダを開き、メンバーの group と同じ名前のフォルダを開きます。
2. 写真を「メンバー名.jpg」という名前で保存して、そのグループのフォルダに入れます。
3. GitHub上の images 内に同じフォルダ構成で写真を追加します。

例：group が「原因は自分にある。」、name が「小泉光咲」の場合
images/原因は自分にある。/小泉光咲.jpg

名前・グループ名はCSVと完全一致させてください。拡張子は .jpg を使います。写真がない場合は自動でプレースホルダーが表示されます。写真はご自身が利用できるものをお使いください。

【ゲームの流れ】
予選で全員が一度ずつ登場し、各4人の中から0〜3人を選びます。選ばれた人だけが一次通過、準決勝へ進みます。準決勝はTOP9の候補が18人以下になるまで選び進めます。最後に2択の決勝を行い、最大9人のTOP9を表示します。各質問への回答は保存され、戻って選び直すとその回答を置き換えます。決勝は選択した瞬間に「決定」が押せます。

【データについて】
同梱の members.csv は、アップロードされた members.xlsx から作成しました。Excelの実データは見出し1行＋メンバー202人です（会話で案内された203人とは1人分差がありました）。不足の可能性がある場合はExcelを確認して、名簿更新の手順で members.csv を差し替えてください。
